# Governance Notes

## Objective
This project demonstrates how data quality monitoring can support a lightweight governance framework for CRM contact data.

## Stewardship Focus
The project assumes a data steward is responsible for monitoring quality issues, coordinating remediation, and validating that business rules are consistently applied.

## Governance Focus
The project connects dashboard-based monitoring with ownership, severity classification, service-level expectations, and periodic review.

## Example Review Questions
- Which business units have the highest concentration of invalid contact data?
- Which issues are recurring across reporting cycles?
- Which issues breach agreed remediation timelines?
- Which rules need to be enforced upstream in source systems?
